# CityFix

CityFix is a civic issue reporting platform that bridges the gap between citizens and local authorities. The platform allows users to report public service issues, engage with the community, and help bring attention to problems that require action.

## Problem Statement

Citizens often encounter issues such as potholes, damaged infrastructure, waste accumulation, faulty streetlights, and other public service concerns. Reporting these issues is frequently inconvenient, fragmented, or lacks transparency.

CityFix provides a centralized platform where citizens can report issues, track community engagement, and encourage faster resolution through public visibility.

## Features

- Report civic issues with images and descriptions
- Location-based issue reporting
- Community upvoting system
- Discussion and feedback through comments
- Public visibility of reported issues
- Browse and explore issues reported by other users
- Designed to improve communication between citizens and authorities

## How It Works

1. Users create an account.
2. An issue is reported with relevant details.
3. The issue becomes visible to the community.
4. Other users can support the issue through engagement and voting.
5. High-priority issues gain visibility and can be escalated to the appropriate authorities.

## Project Motivation

CityFix was developed to encourage civic participation and improve accountability in addressing public service concerns. By creating a transparent reporting system, the platform aims to help communities collaborate in identifying and prioritizing issues that impact daily life.
